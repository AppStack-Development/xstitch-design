## สรุป

ใครก็เปิด “ร้าน” รับผลิตได้ เว็บไม่ได้รับเงินแทน คนซื้อโอนเข้า PromptPay ของร้านโดยตรง
เว็บมีหน้าตั้งราคา หน้าออเดอร์ของทั้งสองฝั่ง แชทในออเดอร์ และรีวิว ทีม XStitch.Design กลายเป็นร้านหนึ่งในระบบเดียวกัน

สั่งผลิตได้ 2 แบบ

- **A. ซื้อจากเจ้าของลาย** — เจ้าของลายในชุมชนตั้งราคาให้ลายของตัวเอง ตัวเลือกไหนไม่มีราคา = สั่งตัวเลือกนั้นไม่ได้ ไม่มีราคาเลย = ไม่มีปุ่มสั่งผลิต
- **B. จ้างผลิตลายของตัวเอง** — ร้านตั้ง “เรตรับผลิต” ครั้งเดียว (วัสดุ ขนาดสูงสุด ราคาตาม S/M/L และชนิดสินค้า ค่าปักต่อฝีเข็ม)
  คนออกแบบกดสั่งผลิตจากหน้าแก้ไขลาย เห็นรายชื่อร้านที่รับลายนี้ได้พร้อมราคาที่คำนวณแล้ว

ชนิดสินค้า: ลาย 3D = ชิ้นงานเปล่า / ชุดปักเอง / ปักเสร็จ · ลายบนผ้า = ชุดปักเอง (ผ้า+ด้าย) / ปักเสร็จ / ปักเสร็จใส่กรอบ
ร้านเขียนคำอธิบายเพิ่มได้ว่าชุดมีอะไรบ้าง

## ขั้นตอนออเดอร์

```
คนซื้อ   เลือกตัวเลือก + ที่อยู่ + ยอมรับข้อกำหนดและการส่งข้อมูลให้ร้าน → ส่งคำสั่งซื้อ      [รอร้านรับ]
ร้าน     รับออเดอร์ / ปฏิเสธพร้อมเหตุผล                                              [รอชำระเงิน]
คนซื้อ   เห็น QR PromptPay ของร้าน → โอน → อัปโหลดสลิป                                [รอตรวจสลิป]
ร้าน     ยืนยันได้รับเงิน → กำลังผลิต → ส่งของ + เลขพัสดุ                               [ชำระแล้ว → กำลังผลิต → จัดส่งแล้ว]
คนซื้อ   กดได้รับของ → รีวิว                                                         [ได้รับแล้ว]
```

## ค่าที่ตกลงแล้ว

| เรื่อง | ตกลง |
|---|---|
| เปิดร้าน | ทุกคนที่เข้าสู่ระบบ: ชื่อร้าน + PromptPay + ยอมรับข้อกำหนดผู้ขาย · ร้านใหม่มีออเดอร์ค้างได้ไม่เกิน 3 จนส่งสำเร็จครบ 3 · ทีมระงับร้านได้ |
| ค่าธรรมเนียมเว็บ | ยังไม่เก็บ |
| ร้านไม่ตอบ | ยกเลิกอัตโนมัติหลัง 3 วัน |
| คนซื้อไม่โอน | ยกเลิกอัตโนมัติหลัง 2 วันนับจากร้านรับ |
| ยกเลิกหลังโอน | ร้านยกเลิกได้ ต้องใส่เหตุผล + ยืนยันว่าคืนเงินแล้ว · คนซื้อขอยกเลิกได้ ร้านตัดสิน · เว็บไม่คืนเงินแทน |
| ไม่ได้ของ | คนซื้อรายงานได้ ทีมดูแชท/สถานะ ระงับร้านได้ แต่บังคับคืนเงินไม่ได้ (เขียนในข้อกำหนด) |
| สิทธิ์ลายแบบ B | ลายที่สร้างเอง หรือดัดแปลงจากลายที่เจ้าของเปิด “อนุญาตให้ผลิต” · ลายจากรูปภาพ ผู้สั่งยืนยันว่ามีสิทธิ์ใช้รูป |
| ตะกร้า | ยังไม่มี ออเดอร์ละ 1 ลาย (หลายชิ้นได้) |
| ราคา | ล็อกตอนสั่ง ออเดอร์เก็บสำเนาลายไว้ |
| แจ้งเตือน | อีเมล: ร้าน = ออเดอร์ใหม่ สลิปใหม่ ข้อความใหม่ · คนซื้อ = รับ/ปฏิเสธ ส่งของแล้ว ข้อความใหม่ |
| ข้อมูลส่วนตัว | ร้านเห็นที่อยู่และสลิปเฉพาะออเดอร์ของตัวเอง · ซ่อนที่อยู่ 30 วันหลังออเดอร์ปิด · ทีมเห็นเฉพาะออเดอร์ที่ถูกรายงาน · PromptPay ของร้านเห็นหลังร้านรับออเดอร์ |
| รีวิว | หลังได้รับของ ออเดอร์ละ 1 (ดาว 1–5 + ข้อความ) ร้านตอบได้ 1 ครั้ง ทีมซ่อนได้ |
| หน้าร้าน | ลายที่ขาย (A), เรตรับผลิต (B), รีวิว, ออเดอร์ที่ส่งสำเร็จ, วันที่เปิดร้าน |
| ออเดอร์เก่า | ย้ายเป็นของร้าน XStitch.Design ออเดอร์ที่เปิดอยู่ทำต่อตามเดิม |
| ข้อกำหนด | ข้อกำหนดผู้ขาย (ใหม่) · ข้อกำหนดผู้ซื้อเวอร์ชันใหม่: เว็บไม่ได้เป็นคู่สัญญาการซื้อขาย · ยินยอมส่งชื่อ ที่อยู่ เบอร์โทรให้ร้าน (PDPA) |

## ช่วงการสร้าง

1. **ระบบร้าน** — ตาราง shops, ออเดอร์ผูกกับร้าน, กฎสิทธิ์ (RLS) ลูกค้า/ร้าน/ทีม + ชุดทดสอบสิทธิ์, หน้าตั้งค่าร้าน,
   หน้า “ออเดอร์ที่ได้รับ” ของร้าน, ย้ายทีมเป็นร้านแรกพร้อมออเดอร์เก่า, อีเมลแจ้งร้าน
2. **แบบ B** — เรตรับผลิตของร้าน, เลือกร้านตอนสั่งจากหน้าแก้ไขลาย (กรองตามวัสดุและขนาด)
3. **แบบ A** — ตั้งราคาให้ลายในชุมชน, ปุ่มสั่งผลิตในหน้าลายเมื่อมีราคา, สวิตช์ “อนุญาตให้ผลิต” ของเจ้าของลาย
4. **ความเชื่อใจ** — รีวิว, หน้าร้านสาธารณะ, รายงานร้าน/ออเดอร์, ยกเลิกอัตโนมัติตามเวลา, “ขอใบเสนอราคา” สำหรับลายที่เกินเรต
   (ทำเป็นสองส่วน: 4ก รีวิว หน้าร้าน แจ้งปัญหาร้าน ยกเลิกอัตโนมัติ ป้าย “สั่งผลิตได้” — migration 0015; 4ข “ขอใบเสนอราคา”)

ข้อควรระวังที่สุด: กฎ RLS ผิดจุดเดียว ร้านหนึ่งอาจเห็นที่อยู่ลูกค้าของอีกร้าน ต้องมีชุดทดสอบสิทธิ์ก่อนเปิดใช้
